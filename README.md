# 📊 미세먼지 농도 예측 _(개인)_

> **[개발기간]** <br />
> 2024.12.02 ~ 12.06 (5일)
> 
> **[주요기능]** <br />
> ① 관리자 페이지: 새롭게 업데이트된 데이터를 **LSTM** 학습 모델로 추가 학습 <br />
> ② 홈 페이지: 미세먼지 실제/예측값 확인
>
> **[FrontEnd]** React, HTML, CSS
>
> **[BackEnd]**  Python, Flask, GCP, MariaDB

<br />
<br />

## 🎞 Youtube

Flask, React, MariaDB 기반으로 개발된 미세먼지 농도 예측 시스템입니다.  
관리자는 데이터를 직접 입력하거나 엑셀로 업로드하고, 사용자는 실시간 예측 결과를 확인할 수 있습니다.
